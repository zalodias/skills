# Implement

Implement the work described by the user in the referenced issue.

## Steps

1. Read the slice issue details (Implementation + Acceptance Criteria)
2. Implement the slice end-to-end outcome.
3. Follow the `/code` skill and existing project patterns.
4. Check off Acceptance Criteria mentally — don’t mark GitHub unless asked.
5. Perform autonomous code review by following the `/review` skill.

## Rules

- No commits, no pull requests — leave that to `/commit` or `/ship`.
- Don’t invent scope beyond the issues.
- Prefer thin, matching changes over speculative abstraction.
